# Observability

One trace spans call/session using trace, call, session and event IDs. Safe JSON logs cover telephony, media, STT, backend, DB, tools, agents and frontend delivery; raw audio, full transcripts/prompts and sensitive/contact values are redacted. Prometheus metrics cover call impact, gaps, reconnects, coach/tool latency, UI reconnect and feedback. Trajectories retain trigger, classification, routing, recommendation IDs and latency, not transcript text. Online evaluation is queued asynchronously and LangSmith is optional.
